# API Architecture (FastAPI v1)

All endpoints under `/api/v1`. AuthN via JWT bearer (user sessions) or
agent enrollment JWT (agent endpoints). AuthZ via RBAC dependency
injection (`require_permission("incident:contain")`) checked server-side
on every request — the frontend's role-based UI is convenience only.

Standard error shape:
```json
{ "error": { "code": "string", "message": "string", "request_id": "uuid" } }
```
No stack traces or internal exception text are ever returned to the client.

## `/api/v1/auth`

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/auth/login` | none | Email+password → JWT (short-lived access + refresh) |
| POST | `/auth/refresh` | refresh token | Rotate access token |
| POST | `/auth/logout` | JWT | Revoke refresh token |
| POST | `/auth/mfa/verify` | partial session | Complete MFA challenge |

## `/api/v1/organizations`

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/organizations` | SUPER_ADMIN/MSSP_ADMIN | List tenants (cross-tenant, explicitly audited) |
| POST | `/organizations` | SUPER_ADMIN | Provision tenant |
| GET | `/organizations/{id}` | member or MSSP_ADMIN | Tenant detail |
| PATCH | `/organizations/{id}` | CLIENT_ADMIN+ | Update tenant settings |

## `/api/v1/assets`

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/assets` | any tenant member | List assets (tenant-scoped) |
| POST | `/assets` | SECURITY_ENGINEER+ | Register asset |
| GET | `/assets/{id}` | any tenant member | Asset detail + current risk |
| PATCH | `/assets/{id}` | SECURITY_ENGINEER+ | Update criticality/zone |
| DELETE | `/assets/{id}` | CLIENT_ADMIN+ | Decommission asset |

## `/api/v1/agents`

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/agents/enroll` | enrollment token | Agent registers, receives agent JWT |
| POST | `/agents/{id}/heartbeat` | agent JWT | Liveness + config pull |
| GET | `/agents` | SOC_ANALYST+ | List agents + status |
| POST | `/agents/{id}/revoke` | SECURITY_ENGINEER+ | Revoke agent credential |

## `/api/v1/telemetry`

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/telemetry` | agent JWT | Ingest batched events (rate-limited, size-capped) |
| GET | `/telemetry` | SOC_ANALYST+ | Query recent events (filter by asset/type/time) |

## `/api/v1/incidents`

| Method | Path | Auth | Description |
|---|---|---|---|

| POST | `/incidents/{id}/assign` | SOC_ANALYST+ | Assign analyst |
| POST | `/incidents/{id}/notes` | SOC_ANALYST+ | Add investigation note |
| POST | `/incidents/{id}/close` | SOC_ANALYST+ | Close (with resolution reason) |

## `/api/v1/threats`

## `/api/v1/risk`

## `/api/v1/reports`

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/reports/incidents/{id}` | any tenant member | Generate incident report (PDF/HTML) from real data |
| GET | `/reports/summary` | any tenant member | Period summary report |

## Contracts

- Every endpoint has an explicit Pydantic request/response model; ORM
  models are never returned directly.
- OpenAPI schema auto-generated by FastAPI and published at `/api/v1/openapi.json`.
- Rate limiting: per-agent on `/telemetry`, per-user on auth endpoints
  (brute-force protection).
